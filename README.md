# The Listening Room

A single-page music site styled as a vintage record player in a warm wooden room, built with Next.js (App Router). Press Play and the tonearm swings onto the record, the platter eases up to 33⅓ rpm, and the song plays with a soft vinyl crackle underneath.

## Run it

```bash
npm install
npm run dev
```

Then open the URL Next prints (port 3000 by default).

## Adding songs (for now)

Songs currently live in a local list. To add one:

1. Put the audio file in `public/audio/` (mp3, wav, etc.) and optional cover art in `public/covers/`.
2. Add an entry to `data/songs.ts` with a title, artist, `audio_url`, optional `cover_url`, and a `created_at` date.

The newest `created_at` goes on the platter first. With one song the record shelf is hidden; with more, they stand on a shelf beside the deck (below it on phones, where there is no room at the side).

The two placeholder tracks were generated by `scripts/make-demo-audio.mjs`. Delete them once real songs are in.

## How it's put together

- `components/Player.tsx` owns playback state: the cue / play / lift sequence, record swaps, volume, and the end-of-side auto-advance.
- `components/Turntable.tsx` and `Turntable.module.css` draw the deck. Everything inside is sized in `cqw` units, so it scales from phone to desktop. `lib/geometry.ts` holds the platter and tonearm layout and works out the arm angle for any groove radius, which is how the arm doubles as the progress indicator.
- `components/Tonearm.tsx` is an SVG arm with counterweight, offset headshell, and cartridge.
- `components/VolumeKnob.tsx` is a drag, wheel, and keyboard-accessible rotary knob.
- `components/SeekRail.tsx` is the brass slide rail under the platter for scrubbing forwards and back.
- `components/RecordShelf.tsx` lists the other records as sleeves on a wooden plank.
- `lib/crackle.ts` synthesises the vinyl hiss, pops, and a once-per-revolution tick with the Web Audio API, so no sample file is needed.
- Textures in `public/textures/` are small SVG noise filters for wood grain, paper, and film grain.

Audio only starts after a tap on Play, which keeps browser autoplay rules happy. No animation libraries are used, just CSS transitions, one `requestAnimationFrame` loop for the platter, and SVG.
